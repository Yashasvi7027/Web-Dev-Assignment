Introduction to Github

To setup git/github and work on a repository-

  • Install git and check if it is installed. To check run this command in the command line: git --version
  • Set the username and email id on Git.
  • Create a Github repository eg. assignment.
  • Now clone the repository through copying the URL from the code section of the repository.
    ie. git clone https://github.com/Yashasvi7027/assignment.git
  • Open its folder.
    ie. cd assignment
  • Create a webpage in the folder using touch command.
    ie. touch firstpage.html
  • Put contents in the html file using nano command.
    ie. nano firstpage.html
  • Check the status of the created file using the command git status.
  • Stage the file using the command git add filename.extentsion.
    ie. git add firstpage.html
  • Commit the staged file and add a message using commit -m command.
    ie. git commit -m "Committed firstpage"
  • Push the repository to github using command git push -u origin main
